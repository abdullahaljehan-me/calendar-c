# 📅 Calendar Application (C)

A lightweight, dependency-free calendar utility written in **C11**.
Generates monthly and yearly calendars, detects leap years, and
calculates the day of the week for any Gregorian date.

---

## ✨ Features

| Feature | Description |
|---|---|
| **Monthly view** | Pretty-prints a single month with aligned day grid |
| **Yearly view** | Full 12-month calendar (3 months × 4 rows) |
| **Leap-year check** | Correctly handles the 100 / 400 divisibility rules |
| **Weekday lookup** | Returns the weekday name for any valid date |
| **Zero dependencies** | Standard C library only — builds on Linux, macOS, Windows |
